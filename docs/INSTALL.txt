Lensyum 1.0 for After Effects (Windows, 64 bit)

Installation
1. Close After Effects.
2. Copy all the files of this folder to
   C:\Program Files\Adobe\Common\Plug-ins\7.0\MediaCore\Lensyum\
   (create the Lensyum folder if it does not exist; administrator rights are required).
3. Reopen After Effects. The effect is under Effect > Lensyum > Lensyum.

The files must stay together in the same folder:
  Lensyum.aex                        the plug-in
  lensyum_ort.dll                    ONNX Runtime, for AI Depth
  onnxruntime_providers_shared.dll   ONNX Runtime
  DirectML.dll                       GPU acceleration for AI Depth
  lensyum_depth.onnx                 Depth Anything V2 Small model
  licenses\                          licenses of the third-party components (keep it)

Without the DLLs or the model the effect still works; only the "AI Depth (auto)"
mode shows a solid red frame. The reason is written to
%TEMP%\lensyum_log.txt.

Requirements: After Effects 2026 (tested with SDK 26.5; earlier versions have not been
tested), Windows 10 or 11 64 bit, a DirectX 12 GPU for AI Depth on the GPU
(otherwise switch off Use GPU and the estimate runs on the CPU).
